# Portfólio — Arthur/Thuko

Site pessoal (portfólio) de **Arthur Henrique (Thuko)**, Desenvolvedor Full-Stack Web/Mobile/Desktop. Uma landing page única, com seções de apresentação, trajetória, projetos, tecnologias e contato, construída com HTML + Tailwind CSS e componentes carregados dinamicamente via JavaScript.

## ✨ Funcionalidades

- **Tema claro/escuro** com botão de alternância (`#theme-toggle`).
- **Layout 100% responsivo**, com menu mobile (hambúrguer) próprio para telas pequenas.
- **Seção "Sobre mim" interativa**: mapa/mind-map animado em SVG (desktop) que se transforma em cards empilhados no mobile.
- **Carrossel de projetos** com scroll horizontal, setas de navegação (desktop) e indicadores/dots (mobile).
- **Grade de tecnologias** com ícones animados ao passar o mouse.
- **Seção de contato** estilizada como terminal de linha de comando.
- Animações suaves (fade-in, blur, pulse) respeitando `prefers-reduced-motion`.

## 🛠️ Tecnologias utilizadas

**No projeto:**
- HTML5
- [Tailwind CSS v4](https://tailwindcss.com/) (via `@import "tailwindcss"`)
- CSS custom properties (temas claro/escuro)
- JavaScript (carregamento de componentes, toggle de tema, mapa interativo e carrossel)
